# Pi 接入与搭子执行记录

2026-10-08。架构评审 9.2 的 Web/服务端实现已落地；协议升级为 0.3.0。未恢复暂停的 goal；Electron、Android 与 skill 不属于本轮。

## 用户现在如何使用

1. 进入搭子，输入问题或从记录、要事、资料库文件进入讨论。同一来源的稳定 ID 对应同一话题；文件改名和正文更新仍回原话题，历史引用保留原版本。
2. 新话题默认关闭「允许联网」。开启后按该话题保存；切换、刷新或跨天继续时恢复对应选择。运行中也可以关闭；后端阻止新搜索/网页读取，并尽力取消在途请求。它不关闭云端对话模型。
3. 发送问题后显示实际执行步骤。模型按需检索本地资料、读取更多正文、搜索或读网页，再给出带编号来源的回答。联网失败说明原因，继续基于已有资料和模型知识分析。DeepSeek 网页接力入口保留。
4. 单次回答最多 6 次生成模型调用、2 分钟、人民币 1 元；记忆提炼也计入。停止时保留已有结果，点击「继续分析」明确追加一轮同样上限，并保留累计调用/费用。相同发送 ID 重试不会另开预算，相同中断结果不能重复追加子执行。
5. 记忆仍只提炼用户明确说过的内容，等用户确认后才更新。停止产生的中途记录不增加成功轮次，也不使旧记忆候选提前过期。会话摘要改为由现有「更新话题摘要」按钮单独触发，不在回答结束后额外自动消费模型调用。

## 实际架构

| 责任 | 实现 |
| --- | --- |
| 模型/图像/工具协议适配 | 锁定 `@earendil-works/pi-ai@1.1.0`，`server/ai/pi-provider.mjs` 使用 Pi 的 OpenAI Completions 适配器；继续读取已有模型设置，不新建第二套密钥配置 |
| 兼容业务调用 | `model-completion.mjs` 仍返回正文或既有用量回执；支持 SSE，以及忽略 stream 参数而返回完整 JSON 的兼容服务；不通过补发请求转换格式 |
| 搭子循环 | `server/agent/chat-agent.mjs` 使用 `@earendil-works/pi-agent-core@1.1.0`；工具串行执行，每轮最多派发 3 个工具，总生成次数仍限制为 6 |
| 只读工具 | `search_local`、`read_source`、`web_search`、`web_read`；没有文件写入、终端、自动要事保存或调研执行工具 |
| 来源验证 | 复用 SQLite 当前版本、来源可读状态、项目范围与有效记忆过滤；读取工具仅能读取已引用/已检索到的来源，外部网页仅能读取已有搜索结果并继续经过公开地址校验 |
| 预算账本 | SQLite settings 的 `chat-run:<opId>`，记录时间、调用、费用预留/回执、步骤、来源和中途结果；网络未知结果保留费用上界，服务重启后不自动再次付费 |
| 会话联网许可 | `chat-policy.mjs`；`thread-web:<threadId>` 持久存储，修改带 revision；每次网页工具派发重新核验，取消信号按会话隔离 |
| 结果写入 | 复用 `conversationRequest` 的同发送 ID 去重、历史签名及来源版本提交前复核；执行绑定原始历史签名，提交失败后的重试不会把旧生成结果套用新历史；原回答删除后不能继续；对话、发送回执和执行对应的 conversationId 在同一事务提交 |
| UI | `useChatExecution.ts` 读取服务端许可、轮询执行进度；`Assistant.tsx` 展示预算、失败/停止原因及确认继续入口 |

原有 LangGraph 调研编排、Qwen 本地 Embedding、ASR、Qdrant 派生索引和 SQLite 业务权威关系不变。Pi 框架不代表新增了所有供应商的原生协议支持；当前沿用设置页的 OpenAI 兼容地址/模型参数。

## 费用口径与明确限制

- 生成预算目前复用已核验的官方 `api.deepseek.com` / `deepseek-flash` 人民币价格快照；2026-11-07 前需复核。其他模型或中转地址缺少计价契约时，在付费派发前停止并显示原因，不按零元处理。
- 工具调用上下文预留采用实际 Pi 请求 JSON 的 UTF-8 字节数 4 倍，加协议余量；最大输出显式限制。返回后复核实际用量是否超出预留上界，异常则停止后续调用。此为保守费用上界，不是供应商账单金额；仍需按实际计价协议维护。
- 搜索复用设置页已有的 Brave 账户人民币费用上限及复核期限；未核对或已过期时搜索工具明确失败，继续已有知识回答。网页读取不收 API 工具费用。
- 本轮自动混合检索采用已确认的本地 Qwen/Qdrant 组合；未就绪则显示关键词降级原因。未知价格的远程 Embedding 不当作免费调用。
- SDK 自动重试关闭。Web 固定发送 opId，重新加载后可重试原操作；旧客户端省略 opId 时不具备跨请求重放保证。
- 2 分钟包含检索、生成和工具等待。取消采用 AbortSignal；无法撤销供应商已经接收和计费的请求，未知用量保留全部预留。
- 无正文、截断、错误引用、来源变更不会冒充成功。长话题仍遵守现有上下文上限，超过时提示更新摘要，不静默删掉历史。

## 协议 0.3.0

新增 `POST /api/v1/threads`、`GET/PATCH /api/v1/threads/:id/web-policy`、`GET /api/v1/chat-runs/:id`；对应旧路径别名遵循已有治理规则。`AskRequest` 增加 continueRunId，Conversation 增加 agentRun，来源会话支持 libraryFile。联网授权以会话策略为准，旧 AskRequest.webSearch 字段不能覆盖运行中的许可。

共 156 个操作映射：153 个现行、3 个退役；159 个具名 Schema。发布顺序是协议提交/tag，然后主仓库更新 Submodule 指针。
