# 拾光 · PersonalAgent Web Demo

一个手机和电脑共用的个人记忆空间：随手记录，找回资料，把积累整理成新的成果。

当前版本的功能清单和「记录一件事到跟进、回看」流程见 [拾光 V1 文档](docs/09-v1-overview.md)。

第二阶段的新增功能、操作流程和验证边界见 [第二阶段开发记录](docs/11-phase2-implementation.md)。

## 直接体验

本机打开 **http://localhost:4317/**，点击「进入演示空间」。初始演示口令为 `shiguang-demo`，可以在「设置与数据」中修改。

Windows 可双击 [打开拾光.url](打开拾光.url)。服务未运行时，双击 [启动拾光.cmd](启动拾光.cmd)，或在本目录运行：

```bash
bash scripts/start.sh
```

当前环境已安装依赖并构建。首次从源码运行需要 Node.js 24+：

```bash
npm ci
npm run build
npm start
```

## 已实现

- 响应式中文界面，Android 浏览器与电脑使用同一服务器、同一空间。
- 记录新增、修改、删除、置顶、标签/项目筛选、中文检索和浏览器草稿恢复。
- TXT/Markdown/CSV/JSON、文字层 PDF、DOCX 导入；图片和音频保留原件，可补充可检索正文。资料库副本解析在独立进程执行，单次两分钟上限；失败保留副本并显示原因。扫描文件信息失败会保留目录进度，可用“重试接入”继续。
- 网页端「记录 → 电脑文件」可浏览/按文件名搜索已映射的 E 盘，并选择文件导入、归纳；记录详情保留电脑原路径。导入时复制独立副本，原文件不会移动或修改。默认映射 WSL 的 `/mnt/e`；如需换目录，启动服务前设置 `COMPUTER_FILES_ROOT` 为绝对路径。
- 浏览器前台录音、文件下载、原文查看。
- 带来源的资料问答、周报/主题整理、成果编辑和 Markdown 导出。
- 问答按话题分会话；同一话题可跨天继续，回答会读取该会话最近六轮，不混入其他话题的聊天历史。
- Web 搭子可以引用已有记录/要事，按「判断、依据、风险与待核实、下一步、可能形成的要事」分析。可生成可编辑的联网搜索简报，复制后在 DeepSeek 网页端开启联网搜索；应用内联网分析需另配 Brave Search API 密钥，由 DeepSeek 模型分析搜索摘要与个人资料。
- 候选记忆确认、生效、暂停、删除；来源变化后重新确认，来源删除后失效。
- 从记录转为要事时会复制来源图片并在要事中展示；使用支持视觉输入的模型时，「AI 辅助编辑」会结合原文和图片填写待确认草稿。
- 共享访问口令、会话隔离、版本冲突保护、重复提交保护和 JSON 导出。
- 可配置兼容模型接口；模型内容须通过基本引用和重复检查，不合格时明确退回原文整理。

数据保存在 `.data/`，刷新页面或重启服务不会清空。默认示例资料为模拟内容。本轮没有扫描或修改 E 盘文件。

记账在电脑端侧栏与手机端设置页保留了“规划中”入口；当前没有账目录入、保存或统计功能。

## 模型与实际边界

本地模型的实测结果见 [验收说明](docs/07-demo-acceptance.md)。本地权重和运行器在 `.local-model/`，不进入 Git；重新安装可在 Linux / WSL x64 上运行 `bash scripts/setup-local-model.sh`，下载约 1.1 GB 权重。没有本机私有模型默认配置时，`bash scripts/start.sh` 会启动可用的本地模型；单独 `npm start` 只启动 Web 服务。

电脑端「设置与数据」和手机端「空间与同步」都可以修改 AI 接口地址、模型名和密钥，并测试已保存的连接。设置里保存的配置优先于启动时的环境变量；密钥不会由设置接口返回。`server/provider.local.mjs` 是这台电脑专用、被 `.gitignore` 排除的源码默认值文件，不能放进手机 App 或公开仓库。

## 查看后端与 AI 调用日志

- 电脑端打开「设置与数据 → 后端 AI 调用日志」，每 5 秒刷新最近的模型请求、响应、token 用量和错误。
- Windows 双击 [查看后端日志.cmd](查看后端日志.cmd)，或在终端运行 `bash scripts/watch-server-log.sh`，可持续查看后端输出；按 Ctrl+C 只会退出查看，不会停止服务。
- 完整后端日志在 `.data/logs/server.log`，AI 请求与响应另存于 `.data/logs/ai-interactions.jsonl`。日志包含发送给模型的资料和返回正文，文件位于被忽略的本地数据目录；密钥不会写入日志。

使用 DeepSeek 的周报和问答调用会关闭默认思考模式，给周报 4096 个输出 token，以免生成预算耗在思考内容后没有正文。若接口仍返回空正文，日志会记录 `finish_reason`、用量和响应内容，前端显示可诊断的错误。

DeepSeek API 当前不提供可直接调用的内置网页搜索；应用内搜索使用 [Brave Search API](https://api-dashboard.search.brave.com/app/documentation/web-search)，密钥可在 Web「设置与数据」中填写，或通过服务端 `BRAVE_SEARCH_API_KEY` 环境变量提供。联网结果是网页摘要，回答附来源链接；重要结论应打开原文核对。跳转 DeepSeek 网页端时不会自动发送个人资料，用户可先编辑简报再复制粘贴。

没有模型时，搜索、原文摘录和资料整理仍可使用；不会把摘录冒充 AI 生成。需要更强写作效果，可在设置中连接其他兼容模型接口。

这是单人共享空间 Demo。Android 原生 App 实施状态见文末；录音详情已接入本地转写（质量仍需核对），网页直接录制已接入，可试听和下载备份；扫描文档 OCR 扩展和后台录音尚未完成。向量检索链路已接入代码，但只有配置 Qdrant 与 Embedding 模型后才启用；未配置时仍使用原有关键词检索。图片理解需视觉模型，音频需本地转写后归纳；扫描件需要补充文字。浏览器关闭后不承诺可靠后台上传。

## Qdrant 混合检索

本机在线检索已切换到Qwen3-Embedding-0.6B（1024维、Q8_0），新索引经逐段覆盖与53来源/20题验收。后台更新由Redis/BullMQ执行，旧BGE集合保留回退。启动、验收与回退命令见[Embedding说明](scripts/embedding/README.md)。

在电脑上运行 Qdrant，并提供兼容 OpenAI `POST /embeddings` 的 Embedding 服务后，设置以下环境变量再启动服务端：

```bash
export QDRANT_URL=http://127.0.0.1:6333
export EMBEDDING_BASE_URL=http://127.0.0.1:11434/v1
export EMBEDDING_MODEL=你的中文向量模型名称
npm start
```

如模型接口需要密钥，再设置 `EMBEDDING_API_KEY`。可用 `QDRANT_COLLECTION` 改集合名前缀。Qdrant 应只供电脑端服务访问，不需要手机直连。服务会把记录和已确认的长期记忆索引到 Qdrant，分别用 dense 向量和精确词项 sparse 向量召回，再用 RRF 融合；SQLite 仍保存权威原文、状态和版本。编辑、删除或暂停后会更新索引，回答前会核对 SQLite 当前版本。首次连接会登记现有资料的后台索引任务，查询不等待全库索引完成；Qdrant 或 Embedding 不可用时会显示错误，不会悄悄退回关键词回答。当前中文词项方案是基础版，需要用真实资料评估效果。 项目过滤分别支持稳定 projectId 和旧项目文字标签；记录、要事、文件共用范围检查。记忆保留 global/project/thread 范围及旧周报/文章用途限制。两路召回使用同一过滤条件，再回查 SQLite；过期候选过多时扩大候选窗口，单次召回窗口最多 1000 个候选，资料库会显示达到上限的提示。新范围元数据在后台补索引期间，部分结果暂未可用。

手机需与电脑处于可互访的网络，访问电脑局域网地址的 `4317` 端口；本机 localhost 已在 Windows 实际验证。局域网防火墙和 WSL 网络模式需按实际环境配置。手机网页录音需要 HTTPS；普通局域网 HTTP 下可使用文件上传。

### 完整备份与隔离恢复

在「设置与数据 → 你的数据，随时带走」点击「创建完整备份」，完成后可下载 ZIP，或点击「验证能否恢复」。验证使用临时目录，不替换当前空间。默认备份包含 SQLite、上传原件、资料副本和成果文件，排除接口密钥和登录凭据；Qdrant 索引需重建。JSON 导出不包含二进制附件。

命令行可执行（目标目录必须不存在）：

```bash
node scripts/backup-data.mjs create .data .data/backups/my-backup
node scripts/backup-data.mjs verify .data/backups/my-backup
node scripts/backup-data.mjs restore .data/backups/my-backup .data/isolated-restore
```

下载的 ZIP 先解压到项目内独立目录，再使用 verify/restore。文件清单、哈希、数据库完整性或附件引用不匹配会中止；恢复不会覆盖已有目录。备份过程中发生写入会提示重试。仅明确需要本地迁移前保留凭据时，创建命令可追加 `--include-secrets`；这类备份不能通过网页下载。恢复/切换在线数据仍需明确指定，隔离验证不会自动切换。

### 文件后台解析

PDF/DOCX 导入先保存原件和 SQLite 任务，再由 API 启动的独立 worker 通过 Redis/BullMQ 解析。详情显示等待、处理中、完成、失败或取消；失败可重试，原件仍可下载。后台结果提交时核对记录版本，用户期间编辑或删除后不会被旧解析覆盖。解析仅提取文字，AI 归纳仍由详情按钮触发；扫描 PDF 未提取到文字时会说明原因。

`npm run dev`、`npm start` 和 `start.sh` 会尝试启动项目本地 Redis（默认 `127.0.0.1:6381`），日志在 `.data/logs/redis.log`。可用 `bash scripts/start-queue.sh` 前台查看 Redis 日志；需要系统 Redis 或 `.local-runtime/redis` 中的可执行文件。已有 Redis 可用 `REDIS_HOST` / `REDIS_PORT` 指定。队列不可用不影响原件保存，任务保留在 SQLite 等待恢复；API/worker 日志会提示连接错误。当前只接入 PDF/DOCX，ASR、索引和提醒任务尚未迁入此队列。


### 录音转写（当前接入范围）

导入录音后，在详情中的「录音转写」选择语言和可选已知人数，点击「开始转写」。处理在本机独立进程和队列进行，页面显示阶段，支持取消、失败后重试。完成后可回听原件、按时间段查看和修订文字，再使用「AI 归纳」；修订后旧总结会显示过期。原始转写与修订内容分别保存，不能用转写结果覆盖用户附记。

本地安装/模型准备见 [ASR脚本说明](scripts/asr/README.md)。默认试验模型large-v3-turbo，CPU int8；当前单段上限30分钟为资源保护限制，尚未验证长录音质量。中文和自动说话人分离仍有误差，需核对，当前未把REC录音验收标为完成。网页「语音记录」支持直接录制、试听、保存及下载备份；需要HTTPS或本机localhost和麦克风权限。转写编辑可逐段修订匿名说话人；设置页独立探测仍在开发。

记录归纳支持长文分段：超过12,000字分段提取后汇总，整次请求共用100秒处理预算，最大100,000字（含转写标记）。任一段失败或模型输出被截断时显示错误，不保存残缺摘要；处理中编辑记录会使旧请求失效。摘要仍是有损归纳，原文与原件始终保留。

### 记录分类整理

新建/编辑记录可直接选择类别，默认保存后由AI自动分类；手动选择与正文同事务保存，失败保留草稿。记录页的「记录类别」可筛选固定类别、开发项目类别或待分类。「整理记录分类」可选择最多100条记录统一改类，人工调整会登记纠错反馈；也可新建开发项目类别、显式选择关联项目并修改类别名称。类别与旧的项目文字标签分别保留，旧记录不会被自动猜测归类。新记录和解析完成的资料会后台自动单分类；详情显示结果/失败原因，支持重试和人工改类。人工分类不会被迟到AI覆盖。侧栏「项目资料」按稳定项目 ID 汇集记录、要事、文件与成果，各组独立分页/重试；可明确关联已有资料并修改项目名称。开发项目类别也参与汇集，单独指定项目优先；旧文字标签不自动合并，聊天不合并。

「设置与数据 → 分类纠错问题表」可查看人工改类反馈，按待处理/已处理筛选并填写处理说明。重新打开问题会保留之前的处理历史；该功能不会自动训练模型或修改程序。

导入文件时可选择类别，也可保持AI自动分类；原件与人工类别一起保存。保存失败时保留所选文件，重试沿用同一导入标识，避免响应丢失导致重复记录。电脑文件导入也支持类别选择。

### 每日待办

普通待办以北京时间切换日期，历史保留。未完成的历史事项可手动加入今天，显示来源日期；按来源去重，不按标题猜测，同名不同事项可以分别安排。同一来源多次转移到今天只有一条；删除今天的转移项后重试不会复活它，需要重新安排时可新建。

### 成果版本

成果人工保存后标为「人工编辑」，保留最初来自AI还是本地整理。网页导出和任务下载都读取当前保存版本；编辑时先保存再导出，其他设备已改动时需重新打开最新成果。旧任务文件不作为当前下载依据。生成期间来源改变或模型输出被截断会报错，不保存残缺成果；资料数量和摘录限制会在详情说明。

### 来源固定讨论

记录详情和要事卡片可点击「与搭子讨论」，自动引用当前资料并回到该来源固定话题。记录与由它生成的要事各有独立讨论，改名不重建会话。映射或历史加载失败会报错，可重试；关联话题已删除时不会自动另建。资料库文件固定会话仍待讨论，本轮未加入该规则。

话题摘要会显示未归纳轮数和失败原因，可在「话题上下文摘要」中更新。回答使用有效摘要与预算内全部未摘要原文；历史改变会停用旧摘要，超预算明确报错。当前使用字符预算；超长轮次可按角色分段压缩，完成段可恢复，每次最多4次调用。全部分段合并成功前不会当作完整摘要；单批上限120,000字符，不宣称无限上下文。

搭子侧栏使用独立话题目录，可点击「更多话题」查找更早讨论；话题内默认显示最近30轮，点击「加载更早消息」继续查看原始历史。分页期间内容改变会提示刷新，避免漏项。

搭子发送现在带操作标识：响应丢失后重试复用同一轮，当前标签页刷新可恢复尚未确认的发送。请求固定所属话题与引用版本；切换话题期间旧回答完成，不会跳回原话题或清掉新输入。旧客户端未携带操作标识时仍按原协议处理。

资料库清单已支持每页30项加载更多、全量状态筛选和错误重试，超过500项也可继续找回；翻页期间资料变化会提示刷新。正文检索与清单分页是不同入口。两者共用项目、来源目录（含子目录）、扩展名、入库日期（北京时间）和状态筛选；展开组合筛选后点击“应用筛选”。正文检索只包含已解析资料。

资料库相同内容共享文件副本，各来源仍保留独立项目、路径和版本；归档一个来源不影响其他来源。旧重复记录会在启动时校验并恢复独立检索入口；无法恢复的记录显示原因，可选择重新复制。

资料库可勾选并批量保留/跳过，每批最多100项；已选清单跨分页和筛选保留。来源已更新或删除时整批不执行，可移除失效项后再提交。网络中断或刷新后，使用“重试确认上次操作”恢复同一批次。

点击资料检索结果可直接定位并高亮对应提取原文，支持切换Markdown阅读。资料版本或片段已变化时会提示重新检索，不使用旧位置误定位。

资料清单和详情分别显示正文解析与向量索引状态；详情自动刷新索引进度。失败时可“重试此文件索引”，无需重做整个资料库。已索引表示当前版本有完成记录，不代表检索服务永远在线。

资料详情可编辑显示标题、标签和项目关联；不会改名或覆盖电脑原件，下载仍保留原文件名。并发修改或项目失效会报错并保留当前编辑输入。

资料详情可关联已有任务，任务详情可查看和移除关联资料。关联保留资料版本；已更新/删除时会提示，执行中需要先暂停才能修改关联。关联本身不会启动任务或确认完成。

资料接入暂停会保留未扫描目录，允许当前文件收尾；继续从原阶段恢复。目录暂时不可读时修复路径后点击“重试接入”，服务重启后在途复制会恢复排队。

资料解析显示编码及异常提示；GB18030为兼容推断，需要核对。空白/无文字层PDF、解析失败和未支持格式分别提示，原副本仍可下载；不会把解析失败内容标成正文已就绪。
