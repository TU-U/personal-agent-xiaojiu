# 拾光第二阶段 · 开发与使用记录

日期：2026-09-28。范围：网页端；不修改、打包或验收原生手机端。

这是第二阶段第一轮实现记录，不等同于产品方案中全部验收指标已达成。

## 已接入的功能

### 个人资料库

记录页 →「资料库」→ 输入 E 盘相对目录 →「扫描并接入」。来源始终只读，副本在 `.data/library/`。

- TXT、Markdown、文字 PDF、DOCX、常见项目源码提取完整正文，按段落切分，保留字符位置。没有旧实现的前 8,000 字截断。
- 跳过依赖、缓存、构建目录和安装产物；无法确定的格式列为待判断。当前自动筛选仍属于文件类型和目录规则初筛，不宣称理解所有文件价值。
- SHA-256 校验复制前后内容，重复内容不重复保存，记录其他来源。源文件变更生成新条目和版本，历史版本保留；删除原件不会删除副本。
- 支持暂停、继续、失败重试、手动保留或跳过；复制中途重启会重新排队。暂不支持单个超大文件的字节级断点续传，100 MB 以上需另行处理。
- 不支持的文件可以复制并标记待解析。图片副本可手动调用视觉模型提取信息，失败会报错，不能把复制成功当作已理解。
- Qdrant 分段 dense 向量 + 哈希词项 sparse 向量，经 RRF 融合。SQLite 保存正文、来源、版本和状态；Qdrant 可重建。旧版本、暂停或未确认记忆不进入默认回答。
- 后台增量索引与提问分离，按分段保存进度；界面显示索引进度和错误。资料库可搜索、查看完整正文、下载副本、引用到搭子继续讨论。

当前本机部署 Qdrant 1.19.1 与 BGE-M3 Q4_K_M，通过已有 llama-server 提供 embedding。仅监听 `127.0.0.1:6333` 和 `127.0.0.1:4319`。启动脚本会复用或启动服务。

首批真实接入「项目实践」20 项：14 份解析成功，1 份重复，5 项待判断。尚未把整个 E 盘筛选完，也没有把这批数量当作最终接入上限。

### 任务协助

搭子讨论 →「从这个话题创建任务」→ 填目标、完成要求、时长和时间 → AI 生成计划 → 查看计划 → 用户确认启动。

任务持久保存目标、计划、工具结果、状态与产物。工具包含：个人资料混合检索、分段读取副本、联网搜索、读取公开文本网页、接入目标中明确指定的来源目录、记录进度、生成 Markdown 产物。

- 默认每轮最多 8 次工具调用、10 分钟，失败最多自动重试 2 次。最后预留产出步骤，优先交阶段报告并说明证据缺口。
- 暂停、继续、取消、失败信息和执行日志可查看。重启后运行中的任务暂停，保留记录，等待继续。
- 未配置应用内搜索时进入「等待外部资料」，提供固定格式简报和 DeepSeek 网页入口；带回资料后可以继续。不会把手动接力说成后台搜索已执行。
- 产物进入「成果」，同时保存为 `.data/task-artifacts/<id>.md`，可下载。AI 产物和工具完成不代表现实中的事情已做完。
- 超过六轮的话题逐步生成可查看的滚动摘要；保留原始对话。摘要不自动进入长期记忆。

### 每日执行与督促

任务可为一次性或每天重复。每个日期单独保存执行记录，主页显示今日任务，任务页可以切换历史。

- 显式开始、暂停计时；补记必须说明原因。服务重启暂停计时，不把停机时段自动算成投入。
- 提交文字证据或本任务成果，AI 给出满足、缺少证据或无法判断及原因。同一成果不能反复用于不同日期的验收。
- 时长达到要求 **且** 证据检查通过，才允许用户最终确认完成；只有报告或只有计时都不行。
- 开始提醒、到期检查、每日最多两次未完成跟进；安静时段可设置。允许指定日期时间稍后检查，也能写原因跳过。
- 提醒在网页首页与任务页显示。电脑服务关闭时不保证准点检查；没有新增系统推送或手机后台能力。
- 原有高等级要事复核、所有要事人工确认、长期记忆人工确认机制保持独立。

## 验证与边界

已通过：TypeScript、网页构建、资料复制/去重/原件不变/长文尾部检索、任务计划确认/工具执行/产物、时长与证据双条件、桌面浏览器导航/表单/复选框/无横向溢出。

本机真实 Qdrant 与 Embedding 已完成首批资料索引，实际语义查询返回文件段落。真实 AI 已生成验收计划；首次执行发现连续检索耗尽预算，随后加入收束规则。修正后真实任务已交付约 6,000 字报告、附 7 个来源，保持待验收状态。验收产物与执行记录可在「任务」查看。

仍需后续验收或扩展：50–200 份资料样本与 20 个标注问题的 Top-5 命中目标、全 E 盘价值筛选、扫描 PDF 的 OCR、音频转写、复杂表格、任务跨重启后的真实长期运行与每日复盘质量。不能将关键词测试或少数语义查询当作 80% 检索准确率的证明。

## 运行和查看日志

- 日常网页：`http://localhost:4317/`，`bash scripts/start.sh`。
- 实时 UI 开发：后端运行时执行 `npx vite --host 127.0.0.1`，浏览 `http://localhost:5173/`。修改前端即热更新；静态 4317 页面需构建并刷新。
- 后端日志：`.data/logs/server.log`；AI 调用见「设置与数据」日志面板或 `bash scripts/watch-server-log.sh`。
- 检索服务：`.data/logs/qdrant.log`、`.data/logs/embedding.log`。
- 此轮开发前已保存 SQLite 备份至 `.data/backups/before-phase2-*.sqlite`。

本机模型与二进制位于被忽略的 `.local-model/`，不属于源码。重装环境需另外准备；可以通过 `QDRANT_URL`、`EMBEDDING_BASE_URL`、`EMBEDDING_MODEL`、`EMBEDDING_API_KEY` 使用兼容服务。
