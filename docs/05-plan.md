## 1. 先完成哪些设计讨论

已确认：以图片描述的 Personal Agent 为方向；先产出设计文档；参考同类产品/开源并给链接与评估；手机 App 与电脑互通；正式手机端优先 Android；Demo 先做网页版。

当前假设：个人自用兼作品展示；首个场景为周报/文章；统一服务端；Android 阶段增加手机离线收集。这些假设可修改，不是已定需求。

| 待定问题 | 建议默认值 | 为什么会影响设计 |

| 面向自己还是商业多人用户？ | 自用兼作品展示 | 决定账号、隔离、运维与分发投入 |

| 是否允许云端处理资料？ | 待明确，不代替用户选择 | 决定模型部署、成本和隐私边界 |
| 开发经验、人数与预算？ | 暂按一名全栈开发者估算 | 决定技术栈和里程碑可行性 |

## 2. 里程碑

先交付 Web Demo，再评估 Android App。以下为一名熟悉相关栈开发者的粗估，未包括平台审核等待，不是交付承诺；模型接入与功能范围确定后重估。

| 阶段 | 预计开发投入 | 可审阅产物与退出条件 |
|---|---|---|
| A：需求与体验定稿 | 2–4 天 | 选定一个主场景、端侧优先级、数据边界；页面线框与验收样本 |
| B：Web 技术验证 | 3–5 天 | Android 与电脑浏览器互通、上传、中文解析、检索；网页前台录音 PoC |
| C：Web Demo | 2–4 周 | 在线资料、引用问答、周报/文章、候选记忆、成果版本、冲突与删除 |
| D：Android App | 3–5 周 | 复用后端；真机录音、离线落盘、待同步队列、续传、进程恢复 |
| E：试用与加固 | 1–2 周 | 固定样本评测、真实资料试用、成本报告、备份恢复与发布准备 |

Web Demo 的退出条件：同账号在 Android 浏览器录入/上传资料，电脑看到解析结果并生成带引用成果，手机能看到成果；纠正记忆后下一次生成采用新值。AI 能力需实际接入，纯静态页面只算交互原型。Android 阶段再验收离线和原生能力，iOS 暂不排期。

## 3. 首版验收目标（非实测结果）

以下为完整首版目标。Web Demo 先验收在线跨端、检索、引用、记忆、隔离和冲突；本地持久保存、离线/断点场景在 Android 阶段验收。

以 1 个用户、1 万条文字记录以内的试用规模设计；文件初始上限建议 50 MB，单条录音建议 30 分钟，需在 PoC 后校准。

| 维度 | 初始目标 | 测量方式 |
|---|---|---|
| 本地保存 | 短文字 P95 小于 1 秒；录音关闭完成后才显示保存成功 | 真机埋点，不含上传 |
| 跨端可见 | 稳定网络、两端前台时，服务端确认后元信息 P95 小于 5 秒 | 不把大附件/AI 处理时长算进元信息指标 |
| 同步正确性 | 重试不重复、冲突不丢内容、删除不复活 | 固定离线/并发/断点场景全部通过 |
| 检索 | 标注问题 Recall@10 ≥ 85% | 至少 60 个中文问题；按资料类型分组报告 |
| 引用 | 关键可核事实引用支持率 ≥ 95% | 人工逐条比对原件；仅链接存在不算正确 |
| 记忆 | 候选被错误自动激活为 0；纠正后后续任务采用新值 | 专门测试范围、时间、矛盾与否定句 |
| 删除与隔离 | 禁止访问样本检索/下载成功数为 0 | 两测试账号、删除中任务和旧引用回归 |
| 价值 | 至少 7 天真实试用，记录周报修改时间与事实错误数 | 与手工写作和无记忆生成作对照 |

ASR 时延、长文生成时延和单任务费用先报告分布，等选定模型与部署再设置门槛。不把“主观流畅”代替任务成功率。

## 4. 评测集与对照

准备经允许使用的 100 条文字、20 张图片、10 段中文录音、10 份 PDF/DOCX，包含专有名词、扫描件、重复资料、过期事实、矛盾日期和错误前提问题。

比较三条路线：纯关键词检索；关键词+向量检索；混合检索+已确认长期记忆。所有路线使用同一生成模型和题目，记录召回、事实正确性、引用、费用、延迟。

另设 20 个记忆更新案例：当前偏好、任务临时要求、历史变更、反事实、第三人称资料、生成稿回流。没有可靠增益时保留简单方案，不因“记忆 Agent”名称而堆叠框架。

## 5. 优先处理的风险

| 风险 | 验证或缓解 |
|---|---|
| 手机后台限制导致误认为已同步 | 本机/上传/云端状态分开；前台强制补拉 |
| 中文人名与项目编号转写错误 | 保留音频定位与手动纠错；专有名词样本评测 |
| 假记忆被不断强化 | 生成稿不自动进入个人事实；来源与候选确认 |
| 多端修改被覆盖 | revision + 冲突副本；不使用设备时间覆盖 |
| 首版范围失控 | 固定两类成果模板，主动连接器后置 |
| 模型/框架能力和宣传不一致 | 使用锁定版本、自有样本与成本日志验证 |
