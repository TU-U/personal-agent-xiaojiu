## 后续确认：技术栈（2026-09-29）

用户确认“按照推荐的来”：引入 Redis + BullMQ、LangGraph JS（先限快速学习/调研模块）、Zod；本阶段不引入 RabbitMQ 或其他 MQ。实施范围、模块依赖和验收见 [18 号方案 TECH-01–03](18-technology-stack-proposal.md) 与 [19 号总执行文档](19-goal-execution.md)。此为已确认开发选型，不代表已安装或验证；ASR/说话人分离具体型号仍未选定。

## 明确的工程解释，不伪称用户逐字指定

- 五轮按候选所在话题成功完成的问答计数，产生后再过5轮到期；别的话题、失败请求和打开页面不计。这一口径在 MEM spec 明示，可按用户后续意见调整。
- 5分钟与1元按单次调研累计系统处理时间/费用记录，包含计划生成、重试和降级；人工审阅或外部网页等待不占运行时长。实现必须展示实际口径并验证接口能否约束费用；没有可靠计费信息不盲调付费服务。
- 记忆规范格式含摘要、范围、来源、版本、候选批次与期限；范围使用全局/项目/话题结构，保留旧用途限制，不在迁移时无声扩大。
- 说话人使用匿名编号，不擅自识别真实身份；录制与转写均要求，但边录边实时显示文字未被明确要求。
