# 产品设计

版本：v0.2 · 2026-09-22

## 1. 从图片中提取的方向

图片描述了四层能力：多模态收集；整理、提炼与归档；基于个人记忆完成写作、调研、办公；在适当时机主动协助。它是一份愿景描述，不能据此推断原产品内部架构或所有能力已上线。

本项目暂名 PersonalAgent。产品定位：一个在手机上随手记录、在电脑上深入工作，并能持续记住用户已确认背景和偏好的个人助手。

用户追加确认：正式手机端优先 Android，手机 App 和电脑互通是基础要求；Demo 先做网页版。

交付分为 Web Demo 与 Android App 两阶段。下文 P0 是 Android 首版完整目标；Web Demo 先实现在线文字/文件收集、检索、引用问答、成果和记忆确认，验证手机浏览器与电脑浏览器互通。网页前台录音列为 PoC 项，失败可改用音频文件上传；原生离线录音、持久上传队列和后台恢复留到 Android 阶段。

## 2. 首版用户与核心价值（待确认）

暂以个人知识工作者、自用兼展示为设计基线。最先解决“资料记了很多，要写东西时找不到、拼不起来”的问题。

衡量价值：用户能否用最近一周的真实资料，在少量修改后得到可用周报；能否点开每条关键事实的原始依据；换设备能否继续工作。

## 3. 功能范围

| 阶段 | 能力 | 边界 |
|---|---|---|
| P0 | 手机文字、录音、拍照/相册、文件导入；电脑文字与文件导入 | 文字/Markdown、JPEG/PNG、音频、PDF、DOCX；不承诺任意 Office 文件 |
| P0 | 同账号跨端同步、手机离线保存、失败重试 | 电脑首版在线工作；手机离线不生成 AI 内容 |
| P0 | 转写/OCR/文档解析、摘要、建议标签 | 原文始终保留；解析失败仍可查看原文件 |
| P0 | 搜索与有引用的问答 | 可按项目、时间、类型限制；无证据时说明不足 |
| P0 | 周报与主题文章草稿 | 先两类任务模板；输出 Markdown，可编辑导出 |
| P0 | 可查看、修改、停用的个人记忆 | 推断记忆先候选，用户确认后生效 |
| P0 | 删除、导出、任务状态、基础账号与设备管理 | 删除覆盖检索索引和派生记忆 |
| P1 | PPTX/XLSX、分享入口、网页剪藏、会议准备 | 分别验证格式和平台限制 |
| P1 | 定时周回顾与用户指定提醒 | 用户开启后触发；有暂停和频率设置 |
| P2 | 日历/邮件等连接器、跨应用执行、电脑安装包 | 根据真实使用需求决定 |

完整愿景保留主动 Agent，但首版先证明记录确实能提高成果质量。首版不自动发邮件、不后台遍历个人电脑文件、不自动导入全部聊天记录。

## 4. 端侧分工

| 手机 App | 电脑工作台 | 共享内容 |
|---|---|---|
| 快速录音、拍照、短文本、查看提醒 | 批量文件导入、长文编辑、引用核对、任务配置 | 资料、标签、项目、记忆、对话、成果版本、任务进度 |
| 本地保存与上传状态 | 多栏浏览与来源对照 | 删除状态和用户偏好 |

手机首页以“记一条”为主操作，电脑首页以“继续工作”为主操作。两端服务同一账号，不要求界面完全相同。

## 5. 页面草案

- **收集箱**：最近资料、处理中/失败筛选、录音与上传入口；新资料无需先选文件夹。
- **资料详情**：原件、转写/解析文本、摘要、标签、归属项目、处理状态；可以纠错并触发重建。
- **问助手**：输入问题、选择资料范围、查看回答与引用；跳转原文位置。
- **任务与成果**：周报/文章入口、生成进度、版本、编辑、导出、重新生成。
- **我的记忆**：事实、偏好、项目背景，显示来源、适用范围与更新时间；候选记忆单独待确认。
- **设置**：设备、同步、模型服务、数据使用说明、删除与导出；主动提醒默认关闭。

电脑推荐左侧导航、中间内容、右侧来源；手机用底部导航与独立来源详情页。信息结构先确定，视觉风格与高保真稿后续讨论。

## 6. 核心旅程与异常

1. 用户手机录制“今天完成了项目 A 的接口联调”。停止录音后立即看到本地记录。
2. 联网后上传，显示“已同步，正在转写”；电脑可先看到记录与附件上传状态。
3. 转写完成，AI 提供摘要与项目建议。用户纠正专有名词，原始录音保留。
4. 电脑选择本周和项目 A，运行“生成周报”。用户看见已完成、风险、下周计划及来源。
5. 若用户说“以后周报先写风险”，界面显示一条可确认的写作偏好；只对周报生效。
6. 用户在电脑保存新版本，手机刷新后可查看；离线编辑产生冲突时保留双方内容。

异常要求：上传中断不丢本地文件；转写失败可单独重试；无足够资料时列出缺口；生成失败保留输入与已完成步骤；记录被删后引用显示失效，不能仍返回已删除原文。

## 7. 首版可演示标准

用同一账号在真实手机与电脑完成以上旅程，包括一次断网录音、一次冲突、一次记忆纠正和一次删除。Web Demo 在 Android 浏览器和电脑浏览器完成在线闭环即可阶段验收；它不代表 Android App 已交付。上述离线录音与进程恢复要求在 Android 阶段验收。
