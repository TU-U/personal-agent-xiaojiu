## 4. 数据兼容、迁移与回退

- SQLite及项目内原件/资料副本是业务权威，Qdrant为可重建索引。新索引按模型/维度/版本隔离，验证后切换，保留旧集合回退路径；不混用旧向量。
- 任务/outbox、调研检查点/预算、操作回执和原件引用是持久业务数据，完整备份覆盖SQLite与附件清单。JSON导出不包含二进制及完整续跑状态，不能替代恢复包。
- 新增实体与字段的实际兼容处理记录在20号各次改动中；历史数据不得伪造发生日期、模型结果、用户确认或说话人身份。读取来源时检查权威版本，旧建议保留历史含义。
- 开发起点源码归档仅是代码回退材料，不是数据库一致性备份。任何线上数据库切换须按独立明确授权处理；目前只做隔离恢复，没有以本验收文档授权覆盖在线数据。
- 默认完整备份排除密钥和会话。恢复到新目录，核对清单、哈希和引用后再决定是否切换；具体命令见运行说明。

## 5. 启动与排障

操作目录：`/mnt/d/OpenResource/PersonalAgent`。现行命令及恢复说明见 [22号运行指南](22-operation-guide.md)。

- `npm run dev`：网页热更新入口通常为localhost:5173，API通常4317；不要同时启动重复API。
- `npm run build`后`bash scripts/start.sh`：构建版本通常localhost:4317；start.sh仅在dist缺失时构建。
- 这些是源码默认端口。2026-10-08后端已按原环境重载，health、`/api/settings/worker`、`/api/settings/storage`均200，worker ready、queueReady=true，见 `artifacts/backend-reload-verified-20261008.json`。本次继续执行时再次读取health返回ok；不将历史PID作为持续在线保证。旧worker路由404缺口已关闭。
- 后台任务依赖Redis/BullMQ；混合检索依赖Qwen embedding与Qdrant；ASR依赖本地Python及模型。生成、视觉、搜索分别按实际配置诊断，health不证明这些能力正常。
- 日志在实际DATA_DIR/logs，AI日志文件ai-interactions.jsonl；`bash scripts/watch-server-log.sh`或“设置与数据”查看。日志有输入输出但脱敏凭据与内联图片，仍应作为个人数据保存。
