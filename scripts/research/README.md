# 调研模型计量专项

运行一次小样本：

```bash
node scripts/research/evaluate-model.mjs
```

脚本只读在线模型配置，隔离 SQLite 预算和 AI 日志，不初始化应用 store、不读取用户记录、不保存业务实体。只发送固定测试词，最多 64 输出 tokens；不会自动重试。结果默认为 `artifacts/research-model-metering.json`，已有结果时拒绝覆盖，避免重复计费。密钥不写入结果。

## 当前价格契约

2026-10-07 核对官方人民币价格后，当前仅接受官方 `https://api.deepseek.com`（含 `/v1`）的 `deepseek-flash`。未知模型或中转地址不能套用其价格。价格版本在 `server/agent/research/research-pricing.mjs`；2026-11-07 起需要重新核对再发起新的付费请求，已结算请求仍可读取原结果。

调用预留按输入未命中缓存的高峰价格和最大输出计费。有效用量返回后仍使用高峰价格上界，缓存命中仅在计数自洽时享受对应价格；峰谷交界、节假日和供应商实际计费时刻无法从响应确认，不把计算值称为实际扣款账单。`usage-upper-bound` 与未知用量的 `upper-bound` 都计入 `uncertainMicros`。每笔取整到微元，不用浮点累计。

纯文本输入采用官方发布的 byte-level BPE 结构：UTF-8 字节数上界，额外预留 1024 个协议 tokens；最大输出使用接口 `max_tokens` 并关闭思考模式。仅发送两个文本消息，无图片、工具定义、JSON schema。官方 tokenizer 包的 SHA256 与来源写入价格快照；其模板/配置不等于在线协议的永久保证。因此这属于工程保守界限，必须逐次比对实际用量，不能把一次小样本当作供应商对硬上限的保证。超界时记录实际费用并停止该研究后续调用；供应商变化导致的未知计费风险仍需在 RES-A08 全链路验收中披露。

空正文、输出截断也可能收费，错误携带用量供结算。网络错误、取消、超时、缺失/矛盾用量不算免费，保留预留上界。已经预留但进程崩溃/租约失效的步骤不能直接再次调用；换尝试编号仍用同一研究预算，不能清零。图节点必须另外绑定业务状态和租约，并为报告收束留出额度，本适配器不代替人工确认或完整调研流程。

来源：[官方人民币价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)、[官方 token 用量说明](https://api-docs.deepseek.com/zh-cn/quick_start/token_usage/)、[官方 tokenizer 文件](https://cdn.deepseek.com/api-docs/deepseek_v4_tokenizer.zip)。

## 应用图与网页链路（2026-10-07）

任务页面的“快速学习与调研”支持建立结构化简报、选择文字记录/要事/已解析副本、由来源话题带入最近6轮背景；规划成功后由小九提示确认。确认与后台执行分离，取消会传播到正在进行的模型请求。结果保存到现有成果，下载从SQLite当前版本生成，不依赖单独的Markdown缓存文件。

`node scripts/research/evaluate-flow.mjs` 会在隔离目录做一次真实模型计划→模拟人工确认→报告测试，默认结果为 `artifacts/research-flow-check.json`，已有证据拒绝重复覆盖。仅固定无个人资料的学习问题，两次模型调用。此测试的确认不属于用户业务事项。

当前实现尚不代表RES整模块完成：Brave费用契约和真实搜索/网页读取、缺口补查与全链路预算仍待补齐；行动候选保存已接入，见后文。网页接力与报告版本的后续进展见下节。已选材料的长文取材已改为按问题关键词扫描全文选段，见下节；不得把它称为完整语义分析。预算已计模型及取材步骤，图编排/本地处理的剩余耗时及收束预留仍需整体核算验收。


## 网页接力与报告版本（2026-10-08）

已确认计划的调研完成或失败后，可整理/编辑网页简报并主动进入等待。简报复用搭子的固定回答格式，由原始背景、约束、问题、引用片段与话题快照确定性生成，不额外调用模型；话题中的助手建议明确不等同用户事实。简报上限64,000字，与生成器可能带入的长背景对齐。

网页回填为独立researchExternal原文实体，最多30,000字及8条HTTP(S)来源链接，保存提交时间而非伪造网页获取时间。回填内容及原始材料均属于不可信资料，进入模型时不执行其中的指令。记录为user_fill/unverified，报告逐段显示未独立核验，附链接不会触发自动读取。任务页可以查看完整回填，即使预算已耗尽或模型再次失败。

回填续用同一任务、同一LangGraph线程、原人工确认和总预算。先持久化reportVersion标记，再从已确认计划节点继续；重启后不会重复重置。每版成果拥有独立ID、researchReportVersion和previousArtifactId，原版保留、可切换和下载；版本号属于本次调研，不等于SQLite实体revision。报告提交前中断恢复使用检查点，不重复付费调用。

`node scripts/research/evaluate-handoff.mjs` 复用已有 `research-flow-check.json` 指向的隔离临时数据库，做一次真实模型回填续跑。缺少原样本、样本已改变或已有结果文件时拒绝重跑，不自动新建付费样本。结果 `artifacts/research-handoff-check.json` 只证明模型处理模拟回填与旧检查点恢复，不代表自动联网已实测。


## 长文取材（2026-10-08，混合检索接入前的本地选段）

`research-evidence.mjs` 对不超过8000字的已选来源保留全文；更长来源扫描全部文本，优先为各个问题选择匹配片段，再用剩余名额补充相关段落。单份最多8段、总长度不超过8000个JavaScript字符串单位，每段保留准确start/end、版本、选段方式和匹配问题编号。100字重叠减少分块边界漏词；无词项匹配时明确标为分布式预览，不冒充语义命中。报告说明仅引用片段，关键词扫描不等于模型理解全文。

选段适用于原文和网页手工回填；回填的提交时间/未核验状态不改变。扫描期间检查任务租约与取材时间上限，失败也计入本地处理时间。既有已结算取材结果和历史检查点仍原样重放，不为更新算法悄悄改变旧报告。本节记录关键词选段阶段；后续已接入自动dense+sparse取材、取消和只读访问，见下节。

验证：`node --test tests/research-evidence.test.mjs tests/research-tasks.test.mjs` 16项通过；随后新增的长文确认→取材→成果保存专项单独通过。没有为选段算法重复付费模型测试。


### 混合检索接入接口

`searchIndex(query, options, config, {readOnly:true, signal, sourceIds})` 可供调研读现有索引。readOnly不自动创建集合或写入索引状态；sourceIds同时约束远端候选与SQL复核；结果必须是当前版本正文的精确slice。调用方signal传递到embedding、Qdrant和响应体，取消不改写为服务不可用。此接口已接入研究图，后续说明见下节；完整调研模块仍待验收。


## 实际混合取材（2026-10-08）

确认计划后的取材逐问题调用本机Qwen/Qdrant，复用已有dense+sparse及范围校验。自动命中保存精确原文位置和版本，在模型调用前与发布时重新核对；旧来源失效的显式重试可重新取材，普通发布中断则直接恢复旧检查点，不重复调用模型。远端embedding尚无费用契约时不会冒充本机免费调用。

`node scripts/research/evaluate-retrieval.mjs` 使用临时SQLite与随机Qdrant集合做真实本机检索，不调用付费生成模型，不用用户资料。结果写入 `artifacts/research-retrieval-check.json`，已有结果拒绝覆盖；结束时仅删除本脚本随机集合。当前样本通过：超过8000字的相关段落被实际检索并保留准确位置。图内模型生成、预算边界和恢复另由针对性测试覆盖，不以单个检索样本声称完整研究质量通过。


## 候选保存（2026-10-08）

报告中的“后续建议”可逐条选择、编辑后保存。要事必须手选等级/类型，可安排检查时间；行动保存为共享监督任务的待确认草稿，由用户执行，确认计划后才开始监督。此入口不调用模型、不调用待讨论ACT工具、不自动完成任务。记录sourceResearch来源与父调研candidateDecisions，旧报告不改写。

同一候选的一次选择跨opId去重，网络响应丢失可恢复原操作。目标/要事检查记录/队列/父调研/操作收据原子提交；旧报告版本、非法候选、越权字段拒绝且保留网页输入。已保存对象删除后明确失效，不因重试自动重建。任务详情可回到来源调研。


## 联网传输基础（2026-10-08，研究图尚待接入）

`searchWeb(query,{signal,key,timeoutMs,returnDetails})` 默认保持原数组返回，结果带search_snippet和retrievedAt。不会静默截断查询；超过600字符/75个空格分隔词会拒绝。401/403、限流、输入、网络和无效响应分别分类，不能把取消/访问拒绝吞成联网失败。只发查询，不发原文或上下文。

`readPublicPage(url,{signal,timeoutMs,start,limit,expectedHash})` 保留最终URL、提取文本位置/总长和contentHash。位置是去标签/归一化后的文本字符串位置；expectedHash不同即拒绝跨版本拼接。重定向逐次校验公开地址并关闭旧响应；DNS和正文均支持取消，总调用共用超时。

官方 [Search定价](https://api-dashboard.search.brave.com/documentation/pricing) 为5美元/1000次；[GET参数](https://api-dashboard.search.brave.com/api-reference/web/search/get) 为最多600字符/75词（2026-10-08核对）。这里不是Answers端点计费。人民币兑换/保守费用契约及实际账户计费尚未核验，不能据美元价宣称1元预算已保证；研究图目前仍显示未发起付费搜索。真实网页读取证据在artifacts/research-public-page-check.json，未进行真实Brave付费调用。


## 研究图联网与搜索费用配置（2026-10-08，新增网页验收待完成）

设置→应用内联网分析下可配置已核对的人民币单次费用上限、复核期限（最长31天）和停用。配置绑定当前Brave密钥，过期或换账户后不发新付费请求。这里保存用户核对的计费上限，不伪称供应商实际扣款；真实账户价格/汇率证据尚未取得时不能关闭RES-A08。

确认计划后研究图逐个问题调用Brave，再尝试读取首条公开文本页；逐条保存搜索摘要与网页文字，费用/时间步骤持久化。网络限流或不可用时保留已有材料、知识回答并标注未核验；访问拒绝、取消、源冲突不降级。搜索用量没有实际账单收据，成功/失败都保守扣已预留上限；缓存重放不再发送请求。所有步骤仍共用原任务账本。

“重新联网取材”在原已确认联网计划上生成新报告版本，不重置预算，旧版可看。它与普通失败恢复不同，后者继续复用已完成图节点。网络权限不足时不要靠重新启动服务碰运气。

### 其他报告类型的定向小样本

仅需补对应类型证据时运行（已有同名结果会拒绝重复计费）：

```bash
node scripts/research/evaluate-flow.mjs /tmp/research-comparison.json comparison
node scripts/research/evaluate-flow.mjs /tmp/research-feasibility.json feasibility
```

使用合成约束，隔离库中模拟确认计划；没有搜索配置时验证已有知识降级，不能称为真实联网。失败会保存错误与预算，不自动重试；修正明确问题后再决定是否重跑。正常结束删除临时provider设置。
